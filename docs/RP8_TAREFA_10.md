# OptiService - Tarefa 10 / RP8

## Código-fonte e documentação no GitHub

Esta entrega consolida a versão final para avaliação acadêmica. O repositório contém o código-fonte, workflows de CI/CD e monitoramento, documentação técnica, diagramas, requisitos e materiais específicos da etapa RP8.

## Como validar a versão

```bash
npm run test
npm run lint
npm run build
```

O workflow `CI/CD OptiService` executa as mesmas verificações na branch `main` antes do deploy no GitHub Pages. O workflow `Monitoramento HTTP` verifica periodicamente se a aplicação publicada responde e contém a identificação OptiService.

## Checklist para submissão

- [ ] Aplicação publicada aberta e com uma conta de demonstração válida.
- [ ] Repositório GitHub acessível.
- [ ] PDFs de relatório, requisitos, diagramas, documentação técnica, validação interna e guia da banca disponíveis.
- [ ] Resultado atual de testes, lint e build registrado.
- [ ] Links do CI/CD e monitoramento incluídos na mensagem de submissão.

## Observação sobre validação do MVP

Qualquer avaliação sem cliente externo deve ser identificada como **validação interna**. Não declarar entrevista, aceite, pontuação SUS, captura de tela ou teste manual sem a respectiva evidência real e datada.
